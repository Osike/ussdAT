# Africa's Talking USSD Demo with Python and Flask

A simple USSD application built with Python, Flask, and the Africa's Talking Sandbox. This project demonstrates how to create a USSD callback endpoint, handle user input, and return interactive menu responses.

**Project status:** Successfully built and tested using the Africa's Talking USSD Simulator.

## Features

- Interactive USSD welcome menu.
- User selection for checking a demo account balance.
- Exit option to end the USSD session.
- Basic handling of invalid menu selections.
- Flask endpoint for receiving USSD callback requests.
- Africa's Talking Sandbox integration for testing.

## Technologies Used

- Python
- Flask
- Africa's Talking Sandbox

## How It Works

The application receives USSD requests through a Flask endpoint. Africa's Talking sends user input to the configured callback URL, and the application returns a response that determines whether the session continues or ends.

- `CON` — keeps the USSD session open.
- `END` — closes the USSD session.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Osike/ussdAT.git
cd ussdAT
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Linux:

```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install flask
```

Save the dependencies:

```bash
pip freeze > requirements.txt
```

### 4. Run the Flask application

```bash
python app.py
```

The application will run locally on:

```text
http://127.0.0.1:5000
```

The USSD callback endpoint is:

```text
http://127.0.0.1:5000/ussd
```

**Note:** Africa's Talking cannot access your local URL directly. You need a public HTTPS callback URL for Sandbox testing.

### 5. Expose the application using ngrok

With Flask running, open another terminal and run:

```bash
ngrok http 5000
```

Copy the HTTPS forwarding URL generated by ngrok.

For example:

```text
https://your-ngrok-domain.ngrok-free.app
```

Your callback URL should be:

```text
https://your-ngrok-domain.ngrok-free.app/ussd
```

Use your actual ngrok URL. The example above is a placeholder.

### 6. Configure Africa's Talking Sandbox

1. Sign in to your Africa's Talking account.
2. Open the Sandbox application.
3. Configure the USSD channel and its callback URL.
4. Set the callback URL to your current ngrok HTTPS URL ending in `/ussd`.
5. Save the configuration.

### 7. Test the application

Open the Africa's Talking Simulator:

https://simulator.africastalking.com:1517/

Select the relevant Sandbox USSD service and start a session.

The application should display the welcome menu and respond to the options selected by the user.

## Troubleshooting

### The simulator displays a generic Africa's Talking message

- Confirm the correct USSD service is selected.
- Verify the callback URL in the Sandbox settings.
- Ensure the URL ends in `/ussd`.
- Check that Flask and ngrok are running.
- Confirm that ngrok is forwarding requests to port `5000`.

### Flask returns `404`

The application defines the `/ussd` endpoint. A request to `/` may return `404` because no homepage route has been configured.

### Flask returns `200`, but the menu does not appear

A `200` status indicates that the server handled the HTTP request successfully. Inspect the response body and confirm that the callback returns the expected USSD text with the appropriate `CON` or `END` prefix.
